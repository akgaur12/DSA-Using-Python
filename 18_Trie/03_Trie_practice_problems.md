# Trie Practice Problems

## Basic Trie Operations (Easy)

1.  Implement a Trie (insert, search, startsWith).
    **\[Very Important\]**
2.  Implement Delete in a Trie, correctly pruning unused nodes.
3.  Count the number of distinct words in a Trie.
4.  Count how many words start with a given prefix.
    **\[Very Important\]**
5.  Find the longest word in the Trie that can be built one
    character at a time by other words in the Trie (Longest
    Word With All Prefixes). **\[Very Important\]**

## Autocomplete & Search Problems (Medium)

6.  Implement an Autocomplete / Type-ahead system using a Trie.
    **\[Very Important\]**
7.  Design Search Autocomplete System (return top-3 historical
    matches by frequency as the user types).
8.  Word Search II — find all dictionary words present in a
    character grid (Trie + Backtracking). **\[Very Important\]**
9.  Replace Words — replace every word in a sentence with its
    shortest root found in a dictionary Trie.
10. Implement a basic Spell Checker (exact match + prefix
    suggestions).
11. Palindrome Pairs — find all pairs of words whose
    concatenation forms a palindrome (Trie-based approach).

## Word Break & Segmentation (Medium/Hard)

12. Word Break I — can a string be segmented into dictionary
    words, using a Trie for prefix lookups.
13. Word Break II — return all possible sentence segmentations.
14. Concatenated Words — find words that are formed entirely by
    other words in the list.

## Counting & Distinct Structures (Medium/Hard)

15. Count Distinct Substrings of a String using a Trie.
    **\[Very Important\]**
16. Number of Matching Words for Each Prefix Query (batch prefix
    counting).
17. Unique Prefix for every word in an array (shortest prefix
    that uniquely identifies each word).
18. Implement a Trie-based Dictionary supporting wildcard search
    (`.` matches any character).

## Bitwise Trie / Binary Trie (Hard)

19. Maximum XOR of Two Numbers in an Array, using a Binary Trie
    over bit representations. **\[Very Important\]**
20. Maximum XOR With an Element From Array (offline queries with
    a Binary Trie).
21. Find the Maximum Subarray XOR using a Binary Trie.
22. Count Pairs With XOR in a Given Range.

## Applied / Design Problems (Hard)

23. Implement IP Routing / Longest Prefix Matching using a Trie
    over binary representations of IP addresses.
24. Design a Phone Directory / Contact search with prefix
    matching.
25. Boggle Game Solver — find all valid dictionary words in a
    letter grid using a Trie to prune invalid search branches.
26. Stream of Characters — check if a suffix of the stream so
    far matches any word in a dictionary (Trie built on reversed
    words).
