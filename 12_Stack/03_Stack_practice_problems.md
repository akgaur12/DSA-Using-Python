# Stack Practice Problems

## Basic Stack Problems

1.  Implement a Stack using an array with push, pop, peek, and
    isEmpty operations.
2.  Implement a Stack using a Linked List.
3.  Implement a Stack that supports `getMin()` in O(1) time.
    **\[Very Important\]**
4.  Implement two stacks in a single array.
5.  Sort a stack using only stack operations (recursion allowed).
6.  Reverse a stack using only stack operations (no extra data
    structure other than recursion).
7.  Delete the middle element of a stack without using any extra
    space.

## Expression-related Problems

8.  Check for balanced parentheses in an expression.
    **\[Very Important\]**
9.  Convert Infix expression to Postfix expression.
10. Convert Infix expression to Prefix expression.
11. Convert Postfix expression to Infix expression.
12. Convert Prefix expression to Infix expression.
13. Evaluate a Postfix expression. **\[Very Important\]**
14. Evaluate a Prefix expression.
15. Design a basic calculator to evaluate a simple expression
    string (supports `+`, `-`, `*`, `/`, parentheses).

## Array/Sequence Problems Solved Using a Stack

16. Next Greater Element for every element in an array.
    **\[Very Important\]**
17. Next Smaller Element for every element in an array.
18. Previous Greater Element for every element in an array.
19. Stock Span Problem.
20. Largest Rectangular Area in a Histogram. **\[Very Important\]**
21. Trapping Rain Water.
22. Maximal Rectangle in a binary matrix.
23. Remove `k` digits to form the smallest possible number.
24. Asteroid Collision.

## Advanced / Design Problems

25. Implement a Min Stack and a Max Stack that both support O(1)
    `push`, `pop`, and `getMin`/`getMax`.
26. Implement a Stack using two Queues.
27. Implement a Queue using two Stacks.
28. Design a browser history feature using stacks (back/forward).
29. Celebrity Problem (using a stack-based elimination approach).
30. The Stock Buy & Sell problem to maximize profit (span-based
    variant using a stack).
