# Dynamic Programming Practice Problems

## 1D DP (Easy/Medium)

1.  Climbing Stairs. **\[Very Important\]**
2.  Fibonacci Number (memoization vs tabulation vs O(1) space).
3.  House Robber — maximum sum of non-adjacent elements.
    **\[Very Important\]**
4.  House Robber II — houses arranged in a circle.
5.  Maximum Subarray Sum (Kadane's, as a DP recurrence).
6.  Decode Ways — number of ways to decode a digit string into
    letters.
7.  Delete and Earn.
8.  Minimum Cost Climbing Stairs.

## Grid DP (Medium)

9.  Unique Paths — number of paths from top-left to bottom-right.
    **\[Very Important\]**
10. Unique Paths II — with obstacles.
11. Minimum Path Sum. **\[Very Important\]**
12. Triangle — minimum path sum from top to bottom.
13. Maximum Path Sum in a Grid with obstacles / cost cells.
14. Cherry Pickup — two paths through a grid.
15. Dungeon Game.

## 0/1 Knapsack Pattern (Medium)

16. 0/1 Knapsack. **\[Very Important\]**
17. Subset Sum — does a subset sum to a target? **\[Very Important\]**
18. Equal Sum Partition — split array into two equal-sum subsets.
    **\[Very Important\]**
19. Count Subsets with a Given Sum.
20. Minimum Subset Sum Difference.
21. Count Partitions with Given Difference.
22. Target Sum — assign +/- signs to reach a target.

## Unbounded Knapsack Pattern (Medium)

23. Coin Change — minimum number of coins. **\[Very Important\]**
24. Coin Change II — number of ways to make an amount.
25. Unbounded Knapsack (items reusable).
26. Rod Cutting Problem.
27. Perfect Squares — fewest square numbers summing to n.

## LCS Family — String DP (Medium/Hard)

28. Longest Common Subsequence (LCS). **\[Very Important\]**
29. Longest Common Substring.

31. Shortest Common Supersequence.
32. Distinct Subsequences — count occurrences of s2 in s1.
33. Longest Palindromic Subsequence.
34. Minimum Insertions/Deletions to make a String Palindrome.

38. Largest Divisible Subset.
39. Longest String Chain.
40. Longest Bitonic Subsequence.
41. Number of Longest Increasing Subsequences.
42. Minimum number of deletions to make array sorted (via LIS).
