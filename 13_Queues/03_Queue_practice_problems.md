# Queue Practice Problems

## Basic Queue Problems

1.  Implement a Queue using an array with enqueue, dequeue, peek,
    and isEmpty operations.
2.  Implement a Circular Queue. **\[Very Important\]**
3.  Implement a Queue using a Linked List.
4.  Implement a Deque (Double-Ended Queue) supporting insertion
    and deletion at both ends.
5.  Implement a Queue using two Stacks. **\[Very Important\]**
6.  Implement a Stack using two Queues.
7.  Implement a Circular Tour / Petrol Pump problem (gas station).
8.  Reverse the first `k` elements of a Queue.
9.  Reverse a Queue using recursion.
10. Interleave the first half of a Queue with the second half.

## Sliding Window / Deque-based Problems

11. Sliding Window Maximum. **\[Very Important\]**
12. Sliding Window Minimum.
13. First negative integer in every window of size `k`.
14. Maximum of all subarrays of size `k` using a Deque.

## BFS-based Problems (Queue as the core data structure)

15. Level Order Traversal of a Binary Tree using a Queue.
16. Rotten Oranges — minimum time for all oranges to rot (grid BFS).
    **\[Very Important\]**
17. Number of Islands using BFS.
18. Shortest path in a Binary Matrix using BFS.
19. Snake and Ladder problem — minimum number of dice throws.
20. Walls and Gates — fill each empty room with distance to
    nearest gate.

## Design / Simulation Problems

21. Design a Circular Queue class from scratch (LeetCode 622
    style, with `enQueue`, `deQueue`, `Front`, `Rear`, `isEmpty`,
    `isFull`).
22. Design an LRU Cache using a Queue/Deque + HashMap.
    **\[Very Important\]**
23. Task Scheduler — arrange tasks with a cooldown period.
24. Generate Binary Numbers from 1 to `n` using a Queue.
25. First non-repeating character in a stream of characters
    (Queue + frequency map).
26. Design a Hit Counter using a Queue (count hits in the last
    5 minutes).
