# Tree Practice Problems

## Traversal Problems (Easy)

1.  Preorder Traversal of a Binary Tree (recursive & iterative).
2.  Inorder Traversal of a Binary Tree (recursive & iterative).
3.  Postorder Traversal of a Binary Tree (recursive & iterative,
    using 1 stack and using 2 stacks).
4.  Level Order Traversal (BFS) of a Binary Tree.
5.  Reverse Level Order Traversal.
6.  Height / Maximum Depth of a Binary Tree.
7.  Count total number of nodes in a Binary Tree.
8.  Count leaf nodes in a Binary Tree.
9.  Check if two Binary Trees are identical.
10. Mirror / Invert a Binary Tree.
11. Check if a Binary Tree is symmetric (mirror of itself).

## Views & Boundary (Medium)

12. Top View of a Binary Tree. **\[Very Important\]**
13. Bottom View of a Binary Tree. **\[Very Important\]**
14. Left View of a Binary Tree.
15. Right View of a Binary Tree.
16. Boundary Traversal of a Binary Tree.
17. Vertical Order Traversal of a Binary Tree. **\[Very Important\]**
18. Diagonal Traversal of a Binary Tree.

## Binary Search Tree Problems (Medium)

19. Search a value in a BST.
20. Insert a value into a BST.
21. Delete a Node in a BST. **\[Very Important\]**
22. Find the Minimum / Maximum value in a BST.
23. Validate if a Binary Tree is a valid BST. **\[Very Important\]**
24. Find the Inorder Successor / Predecessor of a node in a BST.
25. Find the K-th Smallest / Largest element in a BST.
26. Convert a sorted array to a Balanced BST.
27. Construct a BST from a Preorder Traversal.
28. Find the Lowest Common Ancestor (LCA) in a BST.

## Height, Balance & Diameter (Medium)

29. Diameter of a Binary Tree. **\[Very Important\]**
30. Check if a Binary Tree is height-balanced.
31. Convert a Binary Tree into its Sum Tree (each node = sum of
    its subtree).
32. Maximum Path Sum in a Binary Tree. **\[Very Important\]**

## Ancestors & Paths (Medium/Hard)

33. Find the Lowest Common Ancestor (LCA) of two nodes in a
    Binary Tree (not necessarily a BST). **\[Very Important\]**
34. Print all root-to-leaf paths in a Binary Tree.
35. Find the distance between two nodes in a Binary Tree.
36. Print all ancestors of a given node.
37. Find the k-th ancestor of a given node.

## Construction Problems (Hard)

38. Construct a Binary Tree from Inorder and Preorder Traversal.
    **\[Very Important\]**
39. Construct a Binary Tree from Inorder and Postorder Traversal.
40. Serialize and Deserialize a Binary Tree. **\[Very Important\]**
41. Flatten a Binary Tree to a Linked List (in preorder order).

## Advanced Problems (Hard)

42. Binary Tree Zigzag (Spiral) Level Order Traversal.
43. Populate Next Right Pointers in each node (Perfect Binary
    Tree).
44. Check if a Binary Tree is a subtree of another Binary Tree.
45. Merge Two Binary Trees.
46. Count the number of Nodes in a Complete Binary Tree in less
    than O(N).
47. Two-Sum in a BST (find if a pair exists with a given sum).
48. Largest BST Subtree in a Binary Tree.
49. Convert a Binary Tree into a Doubly Linked List (inorder
    order, in-place).
50. Recover a BST in which exactly two nodes have been swapped
    by mistake.
