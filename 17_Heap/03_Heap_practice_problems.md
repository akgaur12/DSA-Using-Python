# Heap Practice Problems

## Basic Heap Operations (Easy)

1.  Implement a Min-Heap from scratch (push, pop, peek).
    **\[Very Important\]**
2.  Implement a Max-Heap from scratch.
3.  Build a Heap from an unsorted array in O(N) time.
4.  Implement Heap Sort. **\[Very Important\]**
5.  Check if a given array represents a valid Min-Heap.
6.  Convert a Min-Heap to a Max-Heap in-place.

## Top-K / Kth Element Problems (Medium)

7.  Kth Largest Element in an Array. **\[Very Important\]**
8.  Kth Smallest Element in an Array.
9.  Top K Frequent Elements. **\[Very Important\]**
10. K Closest Points to Origin.
11. Sort a nearly-sorted (K-sorted) array. **\[Very Important\]**
12. Kth Largest Element in a Stream.
13. Frequency Sort — sort characters by decreasing frequency.

## Two-Heap Pattern (Medium/Hard)

14. Find Median from a Data Stream. **\[Very Important\]**
15. Sliding Window Median.
16. IPO — maximize capital using a max-heap of profits and
    min-heap of capital requirements.

## Merging / Scheduling Problems (Medium/Hard)

17. Merge K Sorted Lists. **\[Very Important\]**
18. Merge K Sorted Arrays.
19. Smallest Range Covering Elements from K Lists.
20. Task Scheduler — minimum intervals with a cooldown period.
    **\[Very Important\]**
21. Reorganize String — no two adjacent characters the same.
22. Meeting Rooms II — minimum number of meeting rooms required.
23. Rearrange characters so that no two adjacent are the same
    (using a max-heap of frequencies).

## Design Problems (Medium/Hard)

24. Design a Priority Queue supporting `increase_key` /
    `decrease_key` (used internally by Dijkstra/Prim's — see
    [`15_Graph`](../15_Graph/03_Graph_Algorithms.py)).
25. LRU/LFU Cache design considerations using a heap for
    eviction ordering.
26. Design a Twitter feed — top K most recent tweets from
    followees (merge-K-lists pattern).

## Advanced / Applied Problems (Hard)

27. Huffman Encoding — build an optimal prefix code using a
    min-heap of character frequencies. **\[Very Important\]**
28. Trapping Rain Water II (3D version, using a min-heap on the
    grid boundary).
29. The Skyline Problem — using a max-heap of building heights.
30. Minimum Cost to Connect Sticks / Ropes.
31. Maximum Performance of a Team.
32. Swim in Rising Water (min-heap variant of the grid-BFS
    problem in [`15_Graph`](../15_Graph/04_Graph_practice_problems.md)).
33. Employee Free Time — merge K sorted interval lists via a
    heap.
