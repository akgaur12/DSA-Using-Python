# Graph Practice Problems

## Basics — Traversal (Easy)

1.  Implement Graph using an Adjacency List / Adjacency Matrix.
2.  Breadth-First Search (BFS) of a Graph. **\[Very Important\]**
3.  Depth-First Search (DFS) of a Graph. **\[Very Important\]**
4.  Number of Provinces / Connected Components in a Graph.
5.  Flood Fill Algorithm.
6.  Rotten Oranges — minimum time for all oranges to rot (grid BFS).
7.  Number of Islands (grid DFS/BFS). **\[Very Important\]**
8.  Detect if path exists between two nodes.

## Cycle Detection & Bipartite Check (Medium)

9.  Detect Cycle in an Undirected Graph (BFS & DFS).
    **\[Very Important\]**
10. Detect Cycle in a Directed Graph (DFS with colors).
    **\[Very Important\]**
11. Check whether a Graph is Bipartite. **\[Very Important\]**
12. Detect a negative-weight cycle using Bellman-Ford.

## Topological Sort (Medium)

13. Topological Sort using DFS. **\[Very Important\]**
14. Topological Sort using Kahn's Algorithm (BFS).
    **\[Very Important\]**
15. Course Schedule I — is it possible to finish all courses
    given prerequisites? **\[Very Important\]**
16. Course Schedule II — return a valid course order.
17. Alien Dictionary — derive character order from a sorted word
    list.
18. Find Eventual Safe States.

## Shortest Path (Medium/Hard)

19. Shortest Path in an Unweighted Graph (BFS).
20. Shortest Path in a DAG (topological order + relaxation).
21. Dijkstra's Algorithm — Shortest Path from a source.
    **\[Very Important\]**
22. Bellman-Ford Algorithm — Shortest Path with negative weights.
    **\[Very Important\]**
23. Floyd-Warshall Algorithm — All-Pairs Shortest Path.
    **\[Very Important\]**
24. Shortest Path in a Binary Matrix.
25. Path with Minimum Effort.
26. Cheapest Flights Within K Stops.
27. Network Delay Time.

## Minimum Spanning Tree & Disjoint Set (Medium/Hard)

28. Minimum Spanning Tree using Prim's Algorithm.
    **\[Very Important\]**
29. Minimum Spanning Tree using Kruskal's Algorithm.
    **\[Very Important\]**
30. Implement Disjoint Set (Union-Find) with Path Compression
    and Union by Rank. **\[Very Important\]**
31. Number of Operations to Make Network Connected.
32. Accounts Merge (Union-Find on shared emails).
33. Most Stones Removed with Same Row or Column.

## Advanced Graph Algorithms (Hard)

34. Strongly Connected Components — Kosaraju's Algorithm.
    **\[Very Important\]**
35. Strongly Connected Components — Tarjan's Algorithm.
36. Bridges in a Graph (Tarjan's Bridge-Finding Algorithm).
    **\[Very Important\]**
37. Articulation Points in a Graph. **\[Very Important\]**
38. Word Ladder — shortest transformation sequence (BFS on an
    implicit graph).
39. Swim in Rising Water.
40. Critical Connections in a Network.

## Miscellaneous / Applied Problems

41. Clone a Graph (deep copy with a hashmap of visited nodes).
42. Snake and Ladder Problem — minimum number of dice throws.
43. Minimum Multiplications to reach End (BFS on states).
44. Find the City With the Smallest Number of Neighbors at a
    Threshold Distance.
45. Reconstruct Itinerary (Eulerian path).
